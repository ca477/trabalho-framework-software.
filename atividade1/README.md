Atividade 1 - Tomcat e Spring MVC

Objetivo 
Configurar o servidor Apache Tomcat para executar uma aplicação Java web utilizando o Spring MVC

Tecnologias
Java
Apache
Spring MVC

Descrição
Esta Atividade tem como objetivo compreender a configuração de um servidor web Java e conhecer a
estrutura básica de uma aplicação desenvolvida com Spring MVC.
